# Vendored JavaScript library

`geneviewer.min.js`, `geneviewer.css`, `themes.json`,
`spec-v1.schema.json`, `geneviewer.standalone.mjs`, `SHA256SUMS` and
`VERSION` are written by `scripts/update_js.py` from a geneviewer-js
release. Do not edit them by hand.

`geneviewer-shiny.js` is this package's own: the Shiny for Python output
binding (`geneviewer.shiny`). The update script leaves it alone.
